# Judo beim TV Bruvi

A responsive, German-language landing page for the TV Bruvi judo club. The site
is a static project with no build step or runtime dependencies.

## Run locally

Open `index.html` in a browser. The page uses Google Fonts when an internet
connection is available and falls back to system sans-serif fonts otherwise.

## Customize

- Update the club copy and add the official contact details in `index.html`.
- Adjust colors, layout, and responsive styles in `styles.css`.
- The small-screen navigation and footer year are handled in `script.js`.
